# Repair CRM SaaS Plan

## Цель

Сделать CRM для небольших сервисов ремонта компьютеров и телефонов: быстрый прием
устройства, прозрачные статусы для клиента, контроль сроков, склад запчастей,
финансы и коммуникации в одном рабочем интерфейсе.

## Персоны

- Владелец сервиса: видит деньги, загрузку мастеров, SLA, склад и филиалы.
- Менеджер приемки: создает клиентов, принимает устройства, меняет статусы.
- Мастер: видит назначенные заказы, диагностику, работы, запчасти.
- Клиент: работает во внешнем клиентском сервисе на домене компании, подает
  заявку, видит статус и сумму по своим устройствам.

## MVP

- Внешняя клиентская часть: отдельный backend/app, синхронизация с CRM через
  server-to-server API и sync-ключ.
- Заказы: статусы `Принят`, `Диагностирован`, `Ожидание запчастей`, `В ремонте`,
  `Тестирование`, `Готов к выдаче`, `Выдан`, `Отменен`.
- Заявка клиента приходит в CRM как pending-действие внешнего клиентского
  сервиса и создает заказ в нужном филиале.
- Клиентский сервис хранит клиентские аккаунты и подтвержденные контакты
  отдельно от staff CRM.
- Заказ хранит историю статусов, журнал действий и произвольные этапы ремонта с
  фото. Сотрудник сам выбирает, какие этапы видны клиенту.
- Сотрудник может отправить клиенту согласование диагностики, работ или суммы.
  Клиент принимает или отклоняет его в кабинете, решение сохраняется в аудите.
- Проверка заказа клиентом живет во внешней клиентской части, CRM отдает туда
  снимки заказов через sync API.
- Обработка ошибок: единый формат JSON, валидация входных данных, понятные
  сообщения без утечки внутренних исключений.
- Docker compose dev/prod, миграции, тесты, pre-commit с black, isort, flake8,
  mypy.

## Следующие коммерческие этапы

- SMS/WhatsApp/Email уведомления по смене статуса.
- QR-ссылка на публичный статус заказа.
- Канбан для мастеров и SLA-эскалации.
- Прайс-листы типовых ремонтов по брендам/моделям.
- Оплаты, чеки, гарантийные документы.
- Мультифилиальность с ролями и ограничением доступа.

## Техническая стратегия

- Backend: Django 6, Django Ninja, PostgreSQL, Redis, Celery, JWT.
- Frontend: Angular 20 standalone components, Angular Material, RxJS.
- Качество: тесты сервисов и API, типизация, линтеры, форматтеры, pre-commit.
- Деплой: Docker compose, отдельные сервисы backend, frontend, db, redis, nginx.
